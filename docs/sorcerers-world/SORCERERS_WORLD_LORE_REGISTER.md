# Sorcerers' World: lore register

Classification for every Sorcerers' World feature. Classes:

- **CANON**: directly established by the manga.
- **CANON-INSPIRED RECONSTRUCTION**: consistent with canon, but exact designs or dimensions are not shown.
- **ORIGINAL EXPANSION**: made up to complete a playable world.
- **ALTERNATE/HYPOTHETICAL**: non-canonical scenarios.

**Verification status.** No chapter or page reference in this file has been checked against the manga in this pass, so
none is quoted. Do not add chapter numbers until someone has checked them against the actual volumes. Facts marked
"brief" come from the owner's design brief and still need a primary-source check before they can be labelled canon.
