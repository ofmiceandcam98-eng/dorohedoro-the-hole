or redistributed.** Every building in the mod is original code (`worldgen/sorcerer/SorcererBuildings.java`).

these pages grants redistribution rights.

## If permission is obtained later

Record here: the permission evidence (message link or screenshot path), the original file's SHA-256, the converted file's
SHA-256, the conversion tool and version, the block remapping table, and the required credit text. Convert with a
verified tool (Sponge or Litematica to structure NBT), never by renaming a file extension. Then open the result in a 1.21.1
test world before it goes anywhere near a structure pool.
