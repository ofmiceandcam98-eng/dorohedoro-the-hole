# Sorcerer Personality Quiz — Complete Answer-to-Magic Key (Pass 19.4)

**Status:** source only; **NOT COMPILED / NOT TESTED IN MINECRAFT.**

On first join: Human or Sorcerer. Sorcerers choose either an 8-question quiz randomly drawn without repeats from the 12-question bank, or a weighted Fate roll that skips the test. There is no unrestricted magic selection.

Every answer awards **+3 primary** and **+1 secondary** affinity. The highest final score wins. Tied maximum scores are resolved by the player choosing **only from the tied highest-scoring types**. The server validates and permanently saves the decision. No gender question, routine reroll or free-type menu.
