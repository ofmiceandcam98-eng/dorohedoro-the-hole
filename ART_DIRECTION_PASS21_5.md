# Art reference and acceptance — Pass 21.5

The first Pass 21.4 draft still felt unlike Minecraft for materials with very few contrast levels and interchangeable silhouettes. This revision edits the actual mod PNG files, without generating unrelated concept art.

## Benchmarks

- **Vanilla Minecraft 1.21.1** original inventory textures: https://mcasset.cloud/1.21.1/assets/minecraft/textures/item
- **Create** metal resources and industrial visual grouping: https://github.com/Creators-of-Create/Create/wiki/Create%27s-Materials
- **Farmer's Delight** readable food ingredients and utensils: https://github.com/vectorwing/FarmersDelight
- **Supplementaries** contained items and fittings: https://www.curseforge.com/minecraft/mc-mods/supplementaries

No benchmark textures are redistributed; these are visual-guidance references. Pixel art changes are original.

## Acceptance gates (not yet passed without running Minecraft)

1. View at actual 16px inventory slot size first, then at 32px, then enlarged 6x for pixel noise.
2. Metals: use glint + dark oxidized edge; crystal: hard facet; viscous: rounded; textiles: fibrous; biological: segmented and not realistic/gory.
3. Tiling: check 3x3 world blocks for unwanted obvious repeat, evaluate next to vanilla materials.
4. View on default GUI backgrounds, default lighting, standard/Fabulous graphics and common shaders.
5. Validate actual on-character, player drops and 3D item render before claiming release quality.

Scope is ART ONLY. Main world-generation quality gate remains before deferred weather/factions/villager content.
